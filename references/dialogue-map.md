# 台词结构图

写正文之前，把原剧每集按节拍拆成台词结构，**只记结构，不记原句**。新剧逐拍对齐这张图，台词逐句自己写。

## 从哪拿

拉片模板每集的 `rawMd`（按集窗口取，见 SKILL.md「输入从哪来」）里有 Storyline（按时间码的剧情）和 Visible Text（逐条字幕）。字幕常常只存到半集，后半段按 Storyline 的转述推，在图里注明哪些时段是推的。

## 每拍记什么

| 字段 | 说明 |
|---|---|
| 轮次 | 大约几个来回 |
| 发言顺序 | 用人设功能位写，如“后妈催 → 继兄假关心 → 父亲压 → 村民两句” |
| 每轮的作用 | 催、激将、撇清、接话反问、控诉、作证、喝止、立誓…… |
| 手法 | 群压 / 接话反问 / 清单控诉 / 围观插话 / 自言自语 / 报数字 |
| 句子形态 | 分句长短、一口气连说几个分句、方言词密度 |

另外记一行整集的形态：几个地点，哪几拍连在同一个地点演，每集时长和口播量。

## 写正文时怎么用

1. 一拍一拍对着写：轮次和手法要对上，内容和措辞全换。
2. **不要逐句翻译**。“对方那句话换几个名词”是复制表达，结构图只给轮次和作用，不给原句。原剧里辨识度高的句子（比如条件对仗句、特别的打趣、标志性的收尾句），连句式也要换掉。
3. 写完跑 `clone_check.py dup 正文.md 原剧语料.txt --k 6`。零星命中的日常口语可以留，不追求 0。命中密集地挤在同一段，一般就是逐句翻译了，那一段要整段重写，不能只换几个字。
