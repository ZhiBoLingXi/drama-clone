# 正文格式

```
## 人物小传
男主姓名（19 岁，男主）：身份。性格：……。说话特点：……。和主角的关系：……。（不写外形）

## 正文

# 第一集

场1-1 地点 日 外
人物：甲 乙 丙
△乙把一盘石磨推到甲面前。
△动作和事件，一行一个。不写外貌、不写画左画右、不写镜头。
甲（把字据往桌上一拍）：台词。
乙（小声）：台词。
甲：台词。
```

- 集标题写 `# 第{中文数字}集`；场头写 `场{集号}-{序号} 地点 日/夜 内/外`，时间只用“日”或“夜”。
- `人物：` 列出在场的角色，可以包括不说话的。
- 台词写 `角色（括注）：台词`。括注写给演员的提示，长短不一，平铺的接话可以不写；项目要求句句带括注时照项目来，但别句句套“（情绪，动作）”两段式。画外音写在括注里，比如 `（画外，嘶哑）`。
- 不写镜头号、分镜、景别、机位、画面位置（画左/画右），不写外貌。
- 正文里只允许这几种行：`# 第N集`、场头、`人物：`、`△` 动作、台词、空行。对位标注（`[原E1-03]`）、`【钩子】`、引用块之类都不进正文；`rules` 会把别的行报成格式问题。
- 龙套用全季唯一的固定称呼，不用“甲乙丙”“A/B”。

## 体量

字数有两个口径：
- **全文字数**：场头、△、括注、台词全算，就是客户说的“剧本字数”。`voice` 报 `totalHan`。
- **口播字数**：只算说出口的台词。`voice` 报 `speechHan`。实测两者大约 4:1，例如一集全文 850 字，口播 213 字。

定目标：
- 用户或客户给了要求（如“每集至少 800 字、成片 100 秒左右”），以要求为准，它是全文下限，用 `voice --min-total 800` 卡住。
- 没给要求时，按原剧这一集的实测时长定口播量。参考值：72 秒一集，口播约 250-400 字；2 分钟一集，约 450 字以内。
- 场次跟原剧走。原剧同一个地点连着演好几个节拍，新剧也连着演，不为凑场数把它切碎。

## 出 Word

`python3 scripts/to_docx.py 剧本.md 剧本.docx` 需要 python-docx（`pip install python-docx`）。
效果：剧名居中，人物小传和每一集都是一级标题，每集另起一页，场头和角色名加粗。
