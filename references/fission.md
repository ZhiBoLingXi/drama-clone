# 外壳裂变

节拍表固定以后，可以换的是**外壳**。一个外壳由四个轴组成，每个候选至少要换掉其中三个：

| 轴 | 例（原剧若是渔乡） |
|---|---|
| 地域 / 行业 | 渔村 → 茶山、草原牧场、古镇酱园、边境口岸、海岛民宿 |
| 主角身份与落差 | 被看不起的渔家女 → 被退婚的制茶传人、被赶出家门的老兽医 |
| 金手指 / 底牌的形式 | 祖传手艺 → 隐藏股权、一纸老契约、被埋没的专利 |
| 关系载体 | 婚姻 / 亲家 → 师徒、合伙、继承、邻里 |

## 候选模板（每个外壳一张）

```
### 候选 X：<一句话 logline，≤20 字，带反差和冲突>
- 外壳：地域/行业 · 主角身份 · 底牌形式 · 关系载体（标出换了哪几轴）
- 人设功能位映射：R1 主角 → …；R2 压迫者 → …（新身份、新动机）
- 现实痛点锚：观众正在焦虑的什么事
- 前 3 集可切片的爽点：各一句
- 为什么看过原剧的人认不出：原剧最强的 3 个指纹，分别被变成了什么
- 风险：哪个节拍在新外壳里不好成立，打算怎么改动机
```

## 动机重找

节拍功能能对齐，动机未必成立。比如原剧里压迫者 R2 是「嫌贫爱富的亲家」，换成师徒外壳以后，R2 压主角的理由要重新找（嫉妒传承、怕被取代），不能硬搬「嫌穷」。动机跟着外壳走，节拍功能保持不变。

## 多变体之间

同一部爆款裂变出 N 部时，把每个变体的外壳四轴列成一张表，任意两部之间至少有三轴不同。否则两部新剧之间就是互相换皮，投放时会撞车。
