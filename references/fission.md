# 外壳裂变

节拍表固定以后，可以换的是**外壳**。一个外壳由四个轴组成，每个候选至少要换掉其中三个：

| 轴 | 例（原剧若是渔乡） |
|---|---|
| 地域 / 行业 | 渔村 → 茶山、草原牧场、古镇酱园、边境口岸、海岛民宿 |
| 主角身份与落差 | 被看不起的渔家女 → 被退婚的制茶传人、被赶出家门的老兽医 |
| 金手指 / 底牌的形式 | 祖传手艺 → 隐藏股权、一纸老契约、被埋没的专利 |
| 关系载体 | 婚姻 / 亲家 → 师徒、合伙、继承、邻里 |

## 候选模板（每个外壳一张）

```
### 候选 X：<一句话 logline，≤20 字，带反差和冲突>
- 外壳：地域/行业 · 主角身份 · 底牌形式 · 关系载体（标出换了哪几轴）
- 人设功能位映射：R1 主角 → …；R2 压迫者 → …（新身份、新动机）
- 现实痛点锚：观众正在焦虑的什么事
- 前 3 集可切片的爽点：各一句
- 为什么看过原剧的人认不出：原剧最强的 3 个指纹，分别被变成了什么
- 金手指对位：前 15 集 powerUse 逐条怎么兑现，哪几条兑现不了
- 风险：哪个节拍在新外壳里不好成立，打算怎么改动机
- 榜单依据：参考了热播榜第几名的哪一点（设定元素、标题句式、形式），或者为什么故意避开榜上扎堆的题材
```

## 先看热播榜（出候选前）

`scripts/hot_rank.py` 抓红果热播榜，写出 `market/hot-YYYYMMDD.md`。读它时看三样：

- **赛道冷热**：原剧的题材现在在榜上热不热。逆袭、玄幻扎堆时，新外壳要么搭这股量，要么换一个榜上少但近期有剧冲上来的题材，说清选哪种、为什么。
- **设定元素和标题句式**：重生年代、末日求生、考试副本、和离带娃、身份反差、「减一斤一个亿」这种数字钩子。这些是公共语法，可以借。
- **续季**：一部剧出到第三季、第七季还在榜上，说明那个设定的观众是追着看的，是很强的需求信号。

借的是公共语法，不借具体表达：榜上剧的剧名、人名、名场面、具体桥段一律不用。

候选只写概念，不写任何样稿场景或台词。节拍表没过 `sheet` 之前写的样稿，会把写手锚死在自己编的开场上。

## 外壳要往下沉、往冲突强的方向换（制作方 2026-11-20）

- 当前阶段投放偏下沉市场。外壳优先选观众身边的行业和关系（家庭、婆媳、打工、小镇、街坊），少选离日常远的高门槛行业。
- 苦情剧也要每集有冲突、有钩子、有悬念，不能平铺。外壳换完以后，原剧的每个爽点在新外壳里要同样狠，最好更狠。
- 面向年轻观众的剧，向冲突强烈的男频剧靠：打脸更直接、反转更快。
- 原剧本身平淡、钩子弱的，在选本阶段就换一部，裂变救不回来。原剧超过 70 集的，要先定好怎么合并压缩。

## 金手指能力对位（选外壳前必查）

原剧每一集靠金手指办成的事（`beats/ep-NNN.json` 的 `powerUse`），新外壳的底牌都要办得成，而且观感同级。先把前 15 集的 `powerUse` 列成清单，逐条写新外壳怎么兑现；兑现不了的，这个外壳就不选，或者写清这一拍改成什么。

常见坑：原剧是**超自然**（续命、隔空把装载机掀翻、二十年容貌不变），新外壳换成**纯技艺**（鉴宝、修复）。前几集的宿命感、第 4 集那种当场震慑全部塌掉，写手只能偷偷换掉节拍，正文就和原剧对不上了。要么新外壳保留同级的超常能力，要么在候选的「风险」一栏写明哪几拍要改。

## 动机重找

节拍功能能对齐，动机未必成立。比如原剧里压迫者 R2 是「嫌贫爱富的亲家」，换成师徒外壳以后，R2 压主角的理由要重新找（嫉妒传承、怕被取代），不能硬搬「嫌穷」。动机跟着外壳走，节拍功能保持不变。

## 多变体之间

同一部爆款裂变出 N 部时，把每个变体的外壳四轴列成一张表，任意两部之间至少有三轴不同。否则两部新剧之间就是互相换皮，投放时会撞车。

- 已有变体登记在工作区的 `variants.json`（立项时 `--axes` 写的四轴），出新一轮候选时 `next` 会列出来，照着避开。
- 变体之间也别撞**主角名**和**台词**：`deliver` 会把这部的剧本和同一原剧其他变体的剧本做连续 8 字查重，并列出选角表里重名的人，写进交付说明。两部都是从同一份台词结构图写出来的，最容易在开场几句上撞。
