# 口语形状库

`oral-shapes.json` 收的是真人说话的**形状**：被打断、抢话、改口、反问代答、重复对方的话、说漏嘴、嘴硬心软……两种条目：
- `example`：自编例句，不出自任何一部剧。
- `refs`：爆款剧、电影里的原台词（《甄嬛传》《让子弹飞》《狂飙》《都挺好》《繁花》等 15 部，46 条），每条带出处和核实用的网页。只收短的几轮，作评析引用，给写手看真人在这种场面下怎么说。**原句一个字都不进剧本**：`check` 会查台词和库里原台词连续 6 字相同，撞上就报。

数据和使用分开：这里只放数据；`clone_check.py brief` 按每一集的节拍挑几条附进任务包，写手照着形状写，换成本剧的人和事。改库不用改代码。

## 一条长什么样

```json
{"id": "interrupt-cut", "scene": "对质", "tags": ["对质", "质问", "逼问"],
 "technique": "话说到一半被对方截断，被截的人不把话说完",
 "example": [["A", "你那天晚上明明在——"], ["B", "在哪？你看见了？"]],
 "note": "被打断的那句用破折号收，不补全"}
```

- `id`：英文短名，全库唯一。
- `scene`：场景类型，一个词。
- `tags`：用来匹配的词。`brief` 拿它和这一集每拍的 `function`、`craft`、原剧台词的语气（`state`）比，命中越多越先选。
- `technique`：一句话说清这个形状。
- `example`：2-5 轮，说话人用 A、B（围观的可以写身份），每句不超过 20 个汉字。
- `refs`：`[{"work": "《剧名》", "context": "谁对谁、什么情境", "lines": [["说话人", "原台词"]], "url": "核实出处的网页"}]`，最多 4 轮。`example` 和 `refs` 至少有一个；同一场景命中一样多时，`brief` 先选带 `refs` 的。
- 加 `refs` 必须先在网页上核对过原话，不凭记忆写；核对不了就不收。
- `note`：为什么像人、写的时候注意什么。

## 往里加

- 只加形状，不加某部剧的原句。从字幕里看到好的说法，抽出形状、自己另编例句。
- 例句里不写「仿佛」「嘴角勾起」这类 AI 腔，不写 △。
- 加完跑 `python3 scripts/clone_check.py library` 校验格式。
- 某部原剧专用的形状，放在原剧工作区的 `oral-shapes.json`（同样的格式），`brief` 会和这里的合在一起用。
